# Changelog

## 0.1.0 Preview 7

- Added a soft, voice-reactive wave inside the bottom edge of the dictation window.
- Added experimental local live Russian dictation with T-one and mode labels in the model list. Other models continue to insert the full transcript after recording. Live insertion depends on the focused editor.

## 0.1.0 Preview 6

- Added light and dark app icons. Settings follows the window appearance, and the bundled layered icon supports macOS icon appearance controls.


## 0.1.0 Preview 5

- Removed the background from the icon artwork so macOS draws a single icon tile.


## 0.1.0 Preview 4

- Updated the app icon in Finder and Settings. The menu bar keeps its fn symbol.

## 0.1.0 Preview 3

- Simplified the keyboard layout correction description in About fnota and the public documentation. Third-party attribution remains in the bundled license notices.

## 0.1.0 Preview 2

- Added a keyboard layout correction section to **About fnota**. It covers setup, correction after Space, and undo with Esc.
- Published the README, build guide, release notes, and installation instructions in English.

## 0.1.0 Preview

- Added optional keyboard layout correction. fnota uses the two languages enabled in macOS and shows the active pair in settings.
- Added undo with Esc, secure-input and app exclusions, and a pause when a conflicting switcher is detected.
- Added a pink Keep Awake indicator beside the menu bar icon.

## Earlier development

- The local browser translation prototype became a native macOS menu bar app with double-press fn to translate.
- Added on-device dictation, text insertion, downloadable models, and permission settings.
- Added Keep Awake and its optional closed-lid helper.
- Added the settings sidebar and About fnota page.

The first public commit records the source as it existed at publication. Earlier Git commits were unavailable in the working copy.
